# HQFAST System Architecture Specification
## 4-Layer Domain-Neutral & Quantum Hardware-Agnostic Software Architecture

**Version:** 0.1.0  
**Specification Document:** ARCH-2026-V1  

---

## 1. Architectural Principles

1. **Hardware-Agnostic Core:** The physics and numerical algorithms (Layer 1) are decoupled from backend hardware dispatchers (Layer 2).
2. **Domain-Neutral Orchestration:** The core tensor network and QUBO engines treat molecular structures as graphs and Hamiltonians, allowing application to battery chemistry, catalysis, or drug design.
3. **Classical-First Compute Hierarchy:** 99.9% of computations execute on classical MPS-DMRG solvers. Quantum hardware and QOBLIB QUBO routines are dispatched only when required.
4. **Zero-Mocking Data Flow:** All presentation dashboards (Layer 4) consume dynamic numerical outputs generated by underlying physical equations.

---

## 2. 4-Layer Software Specification

### Layer 1: Core Physical Mechanics (`src/core/`)
* **`chemistry.py`**: Interfacing PySCF for Hartree-Fock reference calculations, 1-body $h_{pq}$ and 2-body $h_{pqrs}$ molecular orbital integrals, and Full Configuration Interaction (FCI) reference ground truth.
* **`tensor.py`**: Matrix Product State (MPS) tensor decomposition, singular value decomposition (SVD) truncation, and bond dimension ($\chi$) state compression.
* **`mpo_dmrg.py`**: Quimb-backed 2-site variational Density Matrix Renormalization Group (DMRG) sweeps for electronic ground state energy minimization.

### Layer 2: Smart Router, Safeguards & QUBO Engine (`src/orchestrator/`)
* **`cost_guard.py`**: Pre-flight compute cost estimation, RAM usage modeling, $\chi \le 256$ memory clamping, and hard $\$50.00$ execution budget caps.
* **`qubo_engine.py`**: Formulates multi-component electrolyte recipes (Class 06 Portfolio) and interphase density allocation (Class 10 Topology) into QUBO matrices $x^T Q x$.
* **`vendor/qoblib/`**: Isolated open-source QOBLIB matrix builder (`matrix_builder.py`) and solution feasibility verifier (`verifier.py`).
* **`zne.py`**: Zero-Noise Extrapolation error mitigation protocol evaluating noise scaling factors $\lambda \in \{1.0, 3.0, 5.0\}$.
* **`ibm_qpu.py`**: Qiskit IBM Quantum hardware execution driver using EstimatorV2 primitives with human-only dispatch enforcement.

### Layer 3: Multi-Scale SEI Physics Engine (`src/domain/`)
* **`sei_physics.py`**: Solid Electrolyte Interphase kinetics, lithium ion diffusion, solvation shell breakdown, and Arrhenius degradation rate modeling.
* **`equivariant.py`**: E(3)-Equivariant Graph Neural Network force fields, interatomic force vectors, and Cauchy-Virial stress tensor $\mathbf{\sigma}$ calculations.
* **`molecules.py`**: Pre-configured battery molecular library ($\text{LiF}$, $\text{Li}_2\text{CO}_3$, $\text{Li}^+$-EC complex).

### Layer 4: Enterprise SaaS API & Presentation Dashboard (`src/api/`)
* **`main.py`**: FastAPI application exposing REST endpoints (`/simulate`, `/results`, `/prs`, `/api/qubo/solve`, `/api/export/*`) and WebSockets iteration telemetry (`/ws/telemetry`).
* **Static UX Web Pages**: Master UX Studio (`index.html`, `results.html`, `prs.html`) featuring interactive Chart.js graphs, 2D interphase stress heatmap canvas, and 4-format enterprise export hub.

## 3. Data Transfer Objects (DTOs) & Data Flow

```
[Layer 4: User API Request]
       │  (System Name, Atom Spec, Bond Dim χ, Temperature K)
       ▼
[Layer 2: CostGuardEngine Pre-Flight Check]
       │  (Cost Estimation <= $50.00, Clamped χ <= 256)
       ▼
[Layer 1: PySCF & MPO-DMRG Core Engine]
       │  (Electronic Integrals -> MPS Sweep Ground State Energy)
       ▼
[Layer 2: Router / ZNE Extrapolation / QOBLIB Solver]
       │  (Sub-Millihartree Mitigated Energy + QUBO Recipe Vector)
       ▼
[Layer 3: SEI Physics & Equivariant Stress Engine]
       │  (Virial Stress Tensor σ, Dendrite Velocity v, 2D Heatmap Grid)
       ▼
[Layer 4: Web Dashboard & 4-Format Export Hub]
```
